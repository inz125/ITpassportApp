# ITpassportApp

ITパスポートの取得を支援する iPhone 向け Web アプリ。

- 公開 URL: https://inz125.github.io/itpassportapp/
- 開発手順（TDD）: [docs/development.md](docs/development.md)
- 開発ルール: [CLAUDE.md](CLAUDE.md)

## クイックスタート

```bash
npm install
npm run dev        # http://localhost:5173/itpassportapp/
npm run test:watch # TDD 用
npm run check      # コミット前チェック
```
